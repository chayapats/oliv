# Historical personal finetuning tools

The interpreter-based corpus builder and experimental MLX LoRA trainer are
retired from the current checkout. They were retired before the 0.2.0 public release
and are not published. Native training is not implemented by the
current developer CLI; see [../README.md](../README.md) for supported evaluation.

Existing personal datasets and recordings remain local and are not removed or
published by this migration. Never add them to Git.
