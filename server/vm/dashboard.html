ตั้งค่าอุปกรณ์ใหม่ใน 3 ขั้นตอน

  1. สร้าง key โดยตั้งชื่อให้จำอุปกรณ์ได้ เช่น “โน้ตบุ๊กทำงาน”
  2. คัดลอก token ที่แสดงครั้งเดียว เก็บไว้ในที่ส่วนตัว
  3. ตั้ง server.url เป็น https://oliv.example.com และ server.token เป็น token ของอุปกรณ์นั้น

โควตา ≠ ยอดใช้งาน

ยอดใช้วันนี้และยอดรวมคือคำขอที่ตรวจ token ตรงกับ key รวมคำขอที่ผิดพลาดหรือถูกจำกัด ยอดนับโควตาไม่รวมการปฏิเสธเพราะโควตาเต็ม วันนับตาม UTC ประวัติยังอยู่หลัง restart แต่ตัวนับบังคับโควตาเริ่มใหม่เมื่อ API restart
