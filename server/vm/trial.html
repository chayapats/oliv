ติดตั้ง OLIV

บน Mac, Windows หรือ Linux

รับ key แล้วทำตามขั้นตอนของเครื่องคุณ

Mac

วาง key นี้ในแอป OLIV ที่ Settings ช่อง API key

Windows หรือ Linux

ติดตั้ง OLIV แล้วใส่ 2 บรรทัดนี้ใต้ [server] ในไฟล์ตั้งค่า

Windows: %APPDATA%\oliv\config.toml
Linux: ~/.config/oliv/config.toml

เสียงของคุณจะถูกส่งไปถอดความที่เซิร์ฟเวอร์ OLIV แล้วลบทิ้ง ไม่เก็บไฟล์เสียงหรือข้อความไว้บนเซิร์ฟเวอร์ ช่วงทดลองมีจำกัดจำนวนครั้งต่อวัน
