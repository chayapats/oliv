Insightsสิ่งที่เห็นจากผล

OLIV leads overall meaning match on this corpus (97% vs 93%) and returns text slightly sooner after the key is released (median 1.0 s vs 1.4 s). Wispr rewrites numbers and spoken layout commands where OLIV stays literal, and spells dense jargon more cleanly. OLIV นำเรื่องความหมายโดยรวมบนชุดนี้ (97% เทียบกับ 93%) และได้ข้อความเร็วกว่าเล็กน้อยหลังปล่อยปุ่ม (ค่ามัธยฐาน 1.0 วินาที เทียบกับ 1.4 วินาที) ส่วน Wispr เขียนตัวเลขและคำสั่งจัดหน้าใหม่ ในขณะที่ OLIV คงรูปตามที่พูด และ Wispr สะกดศัพท์เทคหนาแน่นได้สะอาดกว่า

Spoken Thai numbers & format commandsตัวเลขไทยที่พูด + คำสั่งจัดหน้า

On nm OLIV 100% vs Wispr 55%. Wispr writes spoken numbers as digits (2.5 GB, 0812345678); the references keep them as words, so this partly measures style, not errors. On fm (OLIV 73% vs Wispr 47%) OLIV keeps line breaks; Wispr often leaves the command words or emits HTML lists.

ชุด nm OLIV 100% เทียบ Wispr 55% Wispr เขียนตัวเลขที่พูดเป็นตัวเลขอารบิก (2.5 GB, 0812345678) แต่ reference เขียนเป็นคำ ส่วนหนึ่งจึงเป็นเรื่องรูปแบบมากกว่าความผิด ชุด fm (OLIV 73% เทียบ Wispr 47%) OLIV คงการขึ้นบรรทัด ส่วน Wispr มักเหลือคำสั่ง หรือทำเป็น HTML list
